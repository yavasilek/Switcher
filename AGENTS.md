# Инструкции проекта Switcher для Codex

- Всегда отвечай пользователю на русском языке.
- Сохраняй существующий стек и выполняй релевантные проектные проверки перед завершением изменений.
- Не публикуй приложение, сайт, релиз или изменения во внешние системы без отдельного разрешения пользователя.

## Work Graph

- Work Graph настроен только для этого репозитория как локальный dev-инструмент и не является частью production runtime.
- Локальный UI запускается командой npm run workgraph:ui на http://localhost:4199/.
- Проверка установки выполняется командой npm run workgraph:doctor.
- В Codex Local и Worktree runner-скрипты определяют текущий checkout самостоятельно; не закрепляй MCP за абсолютным cwd основного репозитория.
- Если в Codex worktree нет собственного node_modules, MCP и UI используют devDependencies основного checkout. Для полностью зелёного doctor и npm-команд выполни npm ci в worktree.
- Для чтения и изменения work items используй MCP-сервер workgraph; не изменяй статусы, результаты проверок и служебные поля в .work.bvc напрямую.
- Автоматические Git snapshots отключены. Не включай их и не вызывай git_snapshot без прямого запроса пользователя.

### Автоматический цикл работы

- Пользователь ставит задачи Codex обычным текстом и не обязан управлять Work Graph вручную.
- Перед изменением кода, тестов, документации или конфигурации найди подходящий незакрытый work item и переиспользуй его без дубликата.
- Если подходящего work item нет, создай его через MCP с понятными basis, vector, goal, проверками, ожидаемыми файлами и ближайшим действием, затем возьми через claim_work_item.
- Во время выполнения поддерживай статус актуальным и добавляй через MCP результаты существенных проверок.
- Перед завершением вызови assert_task_ready_for_done, устрани нарушения и закрой задачу через complete_work_item.
- Простые ответы и чтение без изменений не требуют нового work item, если пользователь явно не попросил их зафиксировать.
- Если MCP временно недоступен, продолжи безопасную работу и синхронизируй карточку после восстановления.
